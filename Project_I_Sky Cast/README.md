# 🌤️ SkyCast – Weather Dashboard

SkyCast is a responsive weather dashboard that provides real-time weather information and forecasts for cities around the world through a clean and modern interface.

## ✨ Features

- 🌡️ Current weather information
- 🔍 Search weather by city
- 🌤️ Hourly weather forecast
- 📅 7-day weather forecast
- 📍 Current location weather
- ⭐ Save favorite cities
- 🌅 Sunrise and sunset timings
- 🌙 Dark and light mode
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API
- Browser Local Storage

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## 🌐 API

Weather data is provided by the [Open-Meteo API](https://open-meteo.com/).

No API key is required.
