# 🛒 SmartCart – Shop Smarter

SmartCart is a modern and responsive e-commerce website built using HTML, CSS, and JavaScript. It provides a simple and interactive online shopping experience with product browsing, cart management, wishlist, and checkout functionality.

## ✨ Features

- Dynamic product display
- Product search and category filtering
- Price sorting
- Add to Cart and quantity management
- Wishlist functionality
- Dark mode
- Cart data saved using LocalStorage
- Checkout modal with customer details
- Order confirmation screen
- Toast notifications
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start shopping!
